# Propuesta: Actualización del README.md (Citas Salón)

Redactar y estructurar el archivo `README.md` principal del proyecto "Citas Salón" (MisCitasApp) en español, proporcionando una visión clara del producto, el stack tecnológico utilizado y las instrucciones necesarias para que los desarrolladores puedan levantar el proyecto localmente.

## 2. Alcance (In Scope)

La actualización incluirá las siguientes secciones clave en el README:

- **Visión del producto**: Descripción del SaaS orientado a la gestión de citas para salones y estéticas.
- **Roles y Audiencia**:
  - Administrador del SaaS (superadmin).
  - Dueños y personal de salones/estéticas (gestión y creación de citas, administración del negocio).
  - Clientes finales (reserva de citas y autogestión).
- **Stack Tecnológico**: Mención detallada de Next.js, TypeScript, Tailwind CSS, shadcn/ui, Prisma, y Supabase (Auth & DB).
