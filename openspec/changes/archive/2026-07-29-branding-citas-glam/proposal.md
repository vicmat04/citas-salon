# Propuesta: Identidad de Marca "Citas Glam" (branding-citas-glam)

## Intención y problema

El proyecto utilizaba el nombre genérico y provisional "Citas Salón" en la interfaz de usuario, metadatos PWA, plantillas de correo y encabezados.

Este cambio actualiza formalmente la identidad visual y textual de la plataforma SaaS al nombre comercial **Citas Glam**.

## Objetivos

1. **Actualización de Metadatos y PWA:** Configurar `Citas Glam` como el nombre principal en `layout.tsx`, `manifest.ts` e íconos móviles.
2. **Actualización de UI:** Reemplazar todas las apariciones visibles de "Citas Salón" por "Citas Glam" en login, registro, landing page, paneles de salón y SuperAdmin.
3. **Comunicaciones por Correo:** Actualizar el asunto, firma y encabezados de las plantillas HTML de correo para reflejar la marca "Citas Glam".
4. **Actualización de Pruebas y Documentación:** Actualizar las pruebas automatizadas y el catálogo de referencia funcional.

## No objetivos

- Alterar rutas de base de datos o slugs de salones existentes.
- Cambiar la estructura de archivos del proyecto ni modificar el paquete de la base de datos.
